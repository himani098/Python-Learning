#### functions
- block of code that performs a particular task
- can be build in type or used defined also
- ex → `print("hello")` → to print output on screen
  - `"hello"` → **argument**
  - `input()` → takes string as an input value
- **side effect** → our output that appears after the execution of program → can be a audio , visual anything
- **bug** → mistake or error in a program
- **return value** → output that a function returns
- **variable** → stores data/value in memory
- `=` → assignment operator
- **comments** → our notes not visible to the computer
- `# for single line comments`
- `"""
  for multi
  line comments
  """`
- **pseudocode** → expressing code in english or human language
- ex →
`name = input("Enter your name: ")
print("Hello, " + name)
print("Hello,", name)`
`+` → printing one big arguments by the held of + to add more things in it → requires space between arguments by user
`,` → taking multiple inputs together → bydefault space present between arguments
- **str** → datatype for string
- **Parameter** → what value a function can take ex-(int)
- **Arguments** → what value we pass to a function ex-(5)
- `\n` → new line character
- `end = '\n'` → end a line with a new line
- `sep = ' '` → separator → adds a space between different arguments
- **positional parameters** → first parameter in print then second then third → come in sequence and proper order
- **named parameters** → no order needed → ex - `sep` , `end`
- `\` → escape characters → used for using different characters and not as python syntax characters
- **format string** → special string
- ex → `print(f"Hello, {name}")`
- `str.strip()` → removes whitespaces from string
- `str.capitalize()` → capitalizes the first letter of the first word of the string
- `str.title()` → capitalizes first letter of each word pf the string
- **methods** → built in function that have already defined values
- `str.split(" ")` → used to split a string into varius substrings on the basis of whitespaces
- **int** → integer datatype → can also be used as a function in type conversion
- **operators in python** → `+`, `-`, `*`, `/`, `%`
- **interactive mode of python** → when we type just python in terminal then it shows >>> where we can perform or execute any single line codes as fast as possible
- **concatenation** → `str1 + str2`
- **float** → decimal number
- **def** → used to define/create a function
- **scope** → anything defined in a block cannot be used outside that scope or block
- `x**2` → x ^ 2
